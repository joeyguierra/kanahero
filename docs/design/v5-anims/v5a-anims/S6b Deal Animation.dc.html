DEAL

THE ARC

Each card starts at the Joker's right hand at 45% scale, tilted −28°, and travels to its slot in one motion. Position runs on an overshoot curve (cubic-bezier(.2,.9,.25,1.12)) so it passes the slot by a few pixels and snaps back; rotation and scale settle on a plain ease-out so the card is flat before it lands.

THE HAND

Order is reading order, left to right, top to bottom — the same order the run will deal them face up. The Joker flicks −7° on each release and recovers before the next. Cards in flight sit above cards already seated.

THE FLOAT

Once seated, a card never sits still. Each one tilts ±5–8° on X and Y under a 520px perspective and bobs 2–3px, on its own 3.6–5s loop with a phase offset — so no two cards move together. Ease-in-out, no pauses, no snap.

renderGrid() on mount, before totals. Budget ≈ 9 × interval + flight ≈ 1.2s at defaults. Respect prefers-reduced-motion: seat all nine at once with a 120ms fade.
