THE ONE SEMANTIC RULE

A card is earned, never shown. Before the first correct write the word exists only as a prompt. For kanji that means no kanji on the card; for kana words it means no kana on the card — romaji and meaning only. The word's first appearance is the earned face.

Rarity is tries, and tries are permanent. 1 = foil, 2 = base, 3+ = worn. Fixed at the first correct write, never upgraded.

Nothing is learned by recognition. The only input is handwriting.

SPECv5 flows, layout law, data shape, scope guard
FLOWS
F10 · ENTER THE ROUND

S1 → deck row → S2/S3 → set row → S6b → DEAL → S7. Four taps, unchanged count. No Joker screen in the path — he is on every screen instead.

F11 · THE LOOP

Unchanged. Prompt → write → FLIP → model over ink → GOT IT / MISSED. Kana words flip to one cell per character, canvas-width ÷ N. Deck at 0 → S8. ✕ abandons and keeps earned cards.

F12 · RESULT AND RE-ENTRY

S8 → BACK TO DECK → S2/S3, set row reads its new fraction. A set at N/N shows the hand instead of DEAL.

F13 · CHARACTERS

S1 → S2 → characters card → S4. The v3 drill, Joker in the header slot. Back is the deck.

F14 · NEW SET

S2/S3 → NEW SET → S6c → SAVE SET → back to the deck, row now present under YOUR SETS with origin: "user". Offline: the status line reads NEEDS A CONNECTION and SAVE is inert — no dialog.

LAYOUT LAW

Primary actions in the bottom 240px, full width, chamfered bottom-left. Strike fill = the act of drilling (START SESSION, OPEN BANK, DEAL, FLIP, CAPTURE). Bone = leaving, reviewing, creating (NEW SET, SAVE SET, BACK TO DECK). Green/amber = self-grade only. Joker component: 78px, 110px on S1 only. Fans may bleed; card content never does; no card text wraps. Result fan is used up to 5 cards; from 6 the result is a 7-column grid (21 max).

BUILD NOTES
DATA SHAPE

Every set: {id, name, glyph, script: "hiragana" | "katakana" | "kanji", origin: "platform" | "user", words:[{word, reading, romaji, meaning}]}. Kana sets carry word === reading. Platform sets ship as JSON; user sets are written by S6c. Progress unchanged: kanahero:v1.joker[setId][wordId] = {tries, rarity, earnedAt}.

DEALER

One module, lib/joker.ts: queue from the unearned list, miss() pushes to the tail with a gap of 2. Lines come from one table keyed by screen and state — the JOKER sheet is the source.

MOTION BUDGET

Exactly two: the flip and the slide. The Joker never animates. prefers-reduced-motion cuts to end state.

REMOVED EVERYWHERE

OFFLINE · $0 · PRESETS · DEALER label · ← JOKER back links · tier words · lock icons · greyed rows · "coming soon" · the v4 S6 Joker screen · any global CTA on S1.

SCOPE GUARD — NOT BUILT, NOT DRAWN

No tier names · no lock icons · no account UI beyond S6c's status line · no HP, turns, opponents · no card effects · no OCR or recognition mode · no sound · no timer · no share, streak, or score beyond the count · nothing greyed, nothing "coming soon".
