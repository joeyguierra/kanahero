THE CONVENTION

S6b uses the S8 row: cards {{ cardW }}×{{ cardH }}, rows bleed to the phone edge with a 12px gutter, dealt left to right so the rightmost card sits on top. Overlap is computed from the row's column count so a full row always spans the 364px width — currently {{ cols }} cols · {{ overlap }}px overlap · {{ visW }}px visible. The second row uses the first row's overlap and left-aligns; it never spreads. Rows are vertically centred between title and totals.

BREAKPOINTS

Two rules. 1–7 words: one row, n columns. 8–21 words: two rows, split even, top row takes the odd card, so columns = ⌈n/2⌉ (4 to 11). Two rows of 118 plus a 10px gap is 246px — DEAL stays above the fold down to a 700px-tall viewport.

NEVER FLIPS

One face only — the pink hatched back with 駅. No inner flip layer, no shine, no tier skin. Pressing DEAL hands this exact layout to S8, which then turns the cards in place. The set and the result are the same object at two moments.

WHY

The v5 4-column grid holds nine. A 21-word set would run to six rows and scroll. Three rows of seven fit an 844px phone but not shorter ones. Two rows, up to eleven wide, are {{ stackH }}px tall at this size — every set from 1 to 21 fits one viewport, totals and DEAL always visible. At eleven wide a face-down card shows 28px; that is fine for a back, and S8 lifts a card to the top on tap once it is face up.

BEFORE → AFTER

Grid 4-col, 9 slots → two rows max, 4–11 cols, up to 21. Dashed empty slots → none; the row fills from the left as cards land. Joker 110px → 78px, as S8. Float tilts ±5–8° on X/Y → bob only (2–3px), because overlapped edges make independent tilt read as jitter. The arc, the flick, the interval and the overshoot are unchanged.

HOOK

Same renderGrid() call, now renderRows(n) with cols = n ≤ 7 ? n : ceil(n/2). S8 Result must adopt the same breakpoints so deal and reveal share one layout. Budget ≈ n × interval + flight ≈ 2.3s at 21 cards; consider 60ms interval above 14. Reduced motion: seat all at once, 120ms fade. Set size is tweakable.

THE ARC

Each card starts at the Joker's right hand at 45% scale, tilted −28°, and travels to its slot in one motion. Position runs on an overshoot curve (cubic-bezier(.2,.9,.25,1.12)) so it passes the slot by a few pixels and snaps back; rotation and scale settle on a plain ease-out so the card is flat before it lands.

THE HAND

Order is reading order, left to right, top to bottom — the same order the run will deal them face up. The Joker flicks −7° on each release and recovers before the next. Cards in flight sit above cards already seated.

THE FLOAT

Once seated, a card never sits still. Each one tilts ±5–8° on X and Y under a 520px perspective and bobs 2–3px, on its own 3.6–5s loop with a phase offset — so no two cards move together. Ease-in-out, no pauses, no snap.

HOOK

renderGrid() on mount, before totals. Budget ≈ 9 × interval + flight ≈ 1.2s at defaults. Respect prefers-reduced-motion: seat all nine at once with a 120ms fade.
