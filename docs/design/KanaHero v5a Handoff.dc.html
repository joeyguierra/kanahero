THE ROW

Head: the word (or the set mark, at 55% strike, when you have never minted it) · the meaning, ellipsised · the row total ×n, or NOT YET. Under it, three equal columns at 5/7, gap 9, each with its ×n under it.

THE FACE HERE CARRIES NO STAMP

A shelf card is the fan card's twin sized by its column. Its chip is the stock name alone — no tries, no · n. Tries are not stored past a run, and rarity already lives in the column.

INVARIANT

Every row sums to the number of finished runs on that set. If two rows disagree, something wrote outside mintRun().

CEILING

21 rows, ~240px each. The head is sticky; the list scrolls under it. Word text never wraps.

RULESWhat the app is now — the part the animations have to stay true to

THE RUN

All-or-nothing. Nothing about a run reaches storage until the queue empties. Abandoning, reloading or closing mid-run discards every card in the hand. One write at the end, mintRun(), every word of it.

The whole set, every time, in a seeded random order (seed logged). A set is always replayable; "nothing left to deal" no longer exists. A miss goes back in the queue with a gap of 2.

Tries live in the round and die with it. 1 try → shiny · 2 → base · ≥3 → worn, fixed at mint.

THE DATA

kanahero:v1 → v3. joker: { setId: { wordId: { shiny, base, worn } } }. No tries, no earnedAt. v2 → v3 is a wipe of joker only; character progress and the Joker's seen key survive.

THE WORD

foil is gone everywhere — copy, storage values, types, class names, lines, e2e. It is shiny.

HOW TO USE THIS SHEET

Every artboard is the shipped tree, not a wish. Draw on top of them: a motion slot wants three frames and a curve, an overlay slot wants one artboard at 390×844 with the layer over a real screen. Anything that changes a number, a line or a rule belongs in a spec first — docs/spec/SPEC-v5a.md §8 is where the creator's part 2 lands, and part 2 may replace any interim Joker line in the table above.

Three things that must survive any animation: the canvas never moves or resizes between prompt and reveal · the Joker's panel never changes height while he talks · nothing says a card is kept before the run finishes.
