The card keeps its full silhouette — same size, same rule, same class tag — so nothing shifts between runs. Where "TICKET GATE" sat, a dash and MEANING OFF in the faint mono. The Joker's line drops the English hint too: he says the kana, not the meaning.

PLACEMENT

One row between the set head and the grid, in the same panel stock as the shelf. Label left, two-segment switch right — identical to DAKUTEN on the deck screen, so the player already knows what it does. Nothing else on the screen moves when it flips.

BEHAVIOUR
