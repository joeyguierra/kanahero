Rules every frame respects (brief §7, spec §5)
· Launch opens S1 for the last-used set; S0 only when there is no last set.
· S1a is asked once per set, the first time it opens, then never again.
· Due first (oldest first), then new, at most 10 new per set; 0 new when due > 20.
· A missed item returns tomorrow, and 5 positions later in the same session. Got it on a fresh day → next rung (1 · 3 · 7 · 14 · 30 days).
· First exposure of any item is a study trial (S2-c): see it once, it melts, write it.
· Self-grade is the only input besides ink. No typing. No loading. No comment on absence, effort or streaks. Rungs and dates never shown except the "next" line.
