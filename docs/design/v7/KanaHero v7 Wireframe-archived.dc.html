Rules the flow must show
· Three decks: Hiragana, Katakana, Kanji. Each deck is one scheduled queue; rows show due · new. Selection is remembered — a returning day is START SESSION → DEAL.
· Due items first, then new. Order is fixed when DEAL is tapped.
· A missed item returns five positions later in the same session (or last, if fewer remain).
· GOT IT on a fresh day moves the item up a rung (1 · 3 · 7 · 14 · 30 days). MISSED drops it to rung 1.
· The user never sees rungs or dates except the "next" line on S5.
· Self-grade is the only input besides ink. No typing anywhere.
· Everything offline; no loading states.
· The Joker sits on top of S0 and S1 and speaks one line per state (deck lines, count lines, a one-time intro). He never comments on absence.
Dashed blue slots are reserved and blank in v7: a one-line message under S1's numbers, the Joker on S4, a pitch-accent line above the kana on S4. No words deck in v7 — S2–S5 keep 水 as a kanji item; multi-character items stay specced for later.
